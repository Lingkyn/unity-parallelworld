# 原始功能卡片

【功能名称】  
玩家死亡与复活系统

【一句话描述】  
玩家进入死亡区域时立即死亡，并在最近激活的复活点复活；预留死亡与复活时的视觉特效扩展口。

【玩家可见行为】
- 进入死亡区域（如深渊、岩浆）时立即死亡
- 死亡后在复活点位置重新出现
- 死亡与复活时可有视觉反馈（VFX 占位，后续可接入）

【触发方式】
- 玩家碰撞体与死亡区域重叠时触发死亡
- 复活由系统自动执行，无需玩家操作

【核心规则】
- 死亡区域：场景中标记为「死亡区域」的碰撞体，玩家触碰即死
- 复活点：场景中标记为「复活点」的位置，玩家经过时激活；死亡后在该点复活
- 若从未经过复活点，则在关卡默认出生点复活

【不做的事】
- 不做血量系统、伤害计算
- 不做存档/读档（与检查点、存档系统分离）
- 不做死亡次数统计、UI 提示（可后续扩展）

# STEP 0.5 — 增强版功能卡片 v1

【功能一句话】  
玩家触碰死亡区域即死亡，在最近激活的复活点复活；预留死亡与复活 VFX 的扩展接口。

【目标】
- 实现「死亡区域 → 死亡 → 复活点复活」的完整流程
- 与既有 MovementController、PlayerToggleController 兼容
- 为死亡/复活 VFX 预留可插拔扩展口

【用户可见行为】
1. 进入死亡区域时立即死亡
2. 死亡后在最近激活的复活点位置复活
3. 经过复活点时激活该复活点（后续死亡将在此复活）
4. 若从未经过复活点，在关卡默认出生点复活
5. 死亡与复活时可有视觉反馈（VFX 占位，后续接入）

【输入/触发】
1. 玩家碰撞体与死亡区域重叠 → 触发死亡
2. 玩家碰撞体与复活点重叠 → 激活该复活点
3. 死亡发生后 → 自动执行复活流程

【输出/反馈】
1. 玩家位置瞬移至复活点
2. 死亡时触发 VFX 扩展口（可空实现）
3. 复活时触发 VFX 扩展口（可空实现）
4. 死亡期间锁定玩家移动与交互

【规则与边界】
1. 死亡区域：使用触发器（Trigger），指定 Layer 标识
2. 复活点：使用触发器，指定 Tag 标识；经过即激活，无需交互
3. 死亡期间：禁用 MovementController、InteractionController、PlayerToggleController，直至复活完成
4. 复活后：0.5–1 秒无敌（Config 可配），期间进入死亡区域不触发死亡；随后恢复控制
5. 双躯体：死亡与复活均作用于当前 active 躯体（Real 或 Shadow），另一躯体同步位置
6. 默认复活点：场景中首个复活点，或关卡配置的出生坐标

【异常与失败路径】
1. 无复活点：使用关卡默认出生点（LevelData 或场景内标记）
2. VFX 未接入：扩展口调用时无实现则跳过，不报错
3. 死亡区域与复活点重叠：死亡优先，复活点不在此次激活

【不做的事】
1. 不做血量、伤害计算
2. 不做存档/读档
3. 不做死亡次数 UI
4. 不做网络同步

【可扩展预留】
1. **死亡 VFX 扩展口**：死亡时在玩家位置调用，可传入位置、朝向等
2. **复活 VFX 扩展口**：复活时在复活点位置调用，可传入位置、朝向等
3. 后续可接入：死亡音效、镜头抖动、复活无敌时间

# STEP 1 — 设计审查

【系统约束声明】  
本项目采用 Presentation / Logic / Infrastructure 三层架构。  
功能必须落在现有层级内。不得新增顶层结构。不得破坏依赖方向。不得产生循环依赖。

**1. 关键架构决策**
- 死亡/复活逻辑放在 Logic 层（DeathRespawnSystem），表现层只做检测与驱动
- 死亡区域、复活点用触发器检测，由 Presentation 层 Collider 驱动
- VFX 扩展口：Logic 层定义接口，Presentation 层实现或注入空实现

**2. 扩展风险**
- 若后续接入检查点/存档，需在复活点激活时写入「当前检查点 ID」，本阶段可预留字段

**3. 实现约束**
1. **死亡/复活时禁用 MovementController、PlayerToggleController**：避免 CharacterController 在瞬移时与物理冲突，死亡期间不可切换躯体
2. **死亡区域 Layer**：需在 Project Settings 中新建（如 DeathZone），Config 引用
3. **复活点 Tag**：使用 Unity 自带「Respawn」，无需新建
4. **Player 识别**：使用 Unity 自带「Player」Tag，Config 默认 "Player"
5. **Physics 碰撞矩阵**：需确保 Player 与 DeathZone Layer 可触发，否则 OnTriggerEnter 不触发
6. **VFX 扩展口**：接口 `IDeathRespawnVFX` 由 Logic 定义，Presentation 注入；未注入时视为空实现，不报错
7. **双躯体同步**：复活后需调用 MovementController 的 SyncXYAndParent，保证 Real/Shadow 位置一致

# STEP 2 — 系统边界

**系统内部（三层）**

| 层级   | 职责单元                                                             |
| ------ | -------------------------------------------------------------------- |
| 表现层 | 死亡区域检测器、复活点检测器、死亡复活控制器（驱动 Logic，注入 VFX） |
| 逻辑层 | 死亡复活系统（规则、状态、复活点记录）                               |
| 数据层 | DeathRespawnConfig（Layer、Tag、默认出生点）                         |

**外部依赖**
- MovementController（禁用/启用）
- InteractionController（禁用/启用）
- Player 根物体（RealPlayer、ShadowPlayer 的父级）
- 场景中的死亡区域、复活点物体

**系统负责**
- 检测死亡区域碰撞 → 触发死亡
- 检测复活点碰撞 → 激活复活点
- 死亡时锁定玩家、调用死亡 VFX 口、执行复活
- 复活时瞬移玩家、调用复活 VFX 口、恢复控制

**系统不负责**
- 死亡区域、复活点的场景摆放
- 存档、检查点持久化
- 血量、伤害计算

# STEP 3 — 状态模型

```
[Alive] ──(进入死亡区域)──> [Dying]
                                │
                                │ 锁定输入、播死亡VFX
                                ▼
[Dying] ──(瞬移完成)──────> [Respawning]
                                │
                                │ 播复活VFX、恢复控制
                                ▼
[Respawning] ─────────────> [Alive]

[Alive] ──(进入复活点)──> 更新「当前复活点」 (无状态迁移)
```

- **Alive**：正常游玩
- **Dying**：死亡中，禁用移动与交互，可选播死亡 VFX
- **Respawning**：复活中，瞬移完成，可选播复活 VFX，随后回到 Alive

# STEP 7 — 接口合同

## 1. IDeathRespawnVFX（VFX 扩展口）

**用途**：预留死亡、复活时的视觉特效扩展，实现时可空。

| 方法      | 参数                              | 行为说明                                 |
| --------- | --------------------------------- | ---------------------------------------- |
| OnDeath   | Vector3 position, Vector3 forward | 死亡时在玩家位置播放特效，forward 为朝向 |
| OnRespawn | Vector3 position, Vector3 forward | 复活时在复活点位置播放特效               |

**不允许依赖**：Logic 层不依赖此接口；由 Presentation 层注入，Logic 通过接口调用。

## 2. DeathRespawnSystem（Logic）

| 方法                       | 参数                                         | 行为说明                                                            |
| -------------------------- | -------------------------------------------- | ------------------------------------------------------------------- |
| NotifyDeath                | —                                            | 触发死亡流程，返回复活目标位置                                      |
| NotifyActivateRespawnPoint | Vector3 position, string checkpointId = null | 激活该复活点，记录为当前复活点；checkpointId 供存档扩展，本阶段可空 |
| GetRespawnPosition         | —                                            | 获取当前复活点位置，若无则返回默认出生点                            |
| GetCurrentCheckpointId     | —                                            | **预留** 供存档读取，返回当前检查点 ID，本阶段可返回 null           |
| SetCurrentCheckpoint       | string checkpointId                          | **预留** 供存档写入，场景加载时恢复检查点，本阶段可空实现           |

## 3. DeathRespawnController（Presentation）

| 职责                                                                   | 说明                                                                            |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| 接收死亡区域、复活点检测结果                                           | 通过事件或直接调用                                                              |
| 调用 DeathRespawnSystem                                                | 获取复活位置                                                                    |
| 禁用 MovementController、InteractionController、PlayerToggleController | 死亡期间                                                                        |
| 瞬移 Player 至复活点                                                   | 设置 Transform.position                                                         |
| 调用 IDeathRespawnVFX.OnDeath / OnRespawn                              | 若已注入                                                                        |
| 恢复 MovementController、InteractionController、PlayerToggleController | 复活完成                                                                        |
| 复活后无敌计时                                                         | 按 Config.respawnInvincibleDuration 计时，无敌期间 DeathZoneDetector 不触发死亡 |

## 4. DeathRespawnConfig（ScriptableObject）

| 字段                      | 类型      | 说明                                                              |
| ------------------------- | --------- | ----------------------------------------------------------------- |
| deathZoneLayer            | LayerMask | 死亡区域所在 Layer                                                |
| respawnTag                | string    | 复活点 Tag，默认 "Respawn"（Unity 自带）                          |
| playerTag                 | string    | 玩家 Tag，默认 "Player"（Unity 自带）；用于检测碰撞对象是否为玩家 |
| defaultSpawnPosition      | Vector3   | 无复活点时的默认出生坐标                                          |
| deathToRespawnDelay       | float     | 死亡特效播放后等待时长（秒），再瞬移复活；0 则立即复活；推荐 0.8  |
| respawnInvincibleDuration | float     | 复活后无敌时长（秒），如 0.5 或 1；已确认选 B                     |

## 5. DeathZoneDetector / RespawnPointDetector

- 挂于对应物体，使用 OnTriggerEnter（3D 项目用 BoxCollider/SphereCollider，IsTrigger=true）
- 过滤：仅当碰撞体 Tag 为 Config.playerTag（默认 "Player"）时触发
- 通过事件或 Controller 引用通知 DeathRespawnController
- **RespawnPointDetector 预留**：`checkpointId`（string）供存档；`order`（int）用于「场景首个」排序，FindGameObjectsWithTag 后按 order 升序取最小为默认复活点，order 相同时按 position.x

**关键实现要点**：
- 死亡时：`MovementController.enabled = false`，`InteractionController.enabled = false`，`PlayerToggleController.enabled = false`
- 复活时：先 `transform.position = respawnPos`，再 `SyncXYAndParent`（通过 MovementController 或直接操作），最后恢复 MovementController、InteractionController、PlayerToggleController 的 `enabled = true`
- VFX：Controller 持有 `IDeathRespawnVFX _vfx`，调用前 `if (_vfx != null) _vfx.OnDeath(...)`，未注入不报错
- 双躯体：瞬移 Player 根物体即可，Real/Shadow 为子物体，会跟随；复活后若需同步可调用 MovementController 的 Sync 逻辑
- **复活无敌（已确认 B）**：DeathRespawnConfig 增加 respawnInvincibleDuration（float）；DeathRespawnController 复活后启动 `_invincibleTimer`，每帧递减；DeathZoneDetector 或 Controller 收到死亡事件时，若 `_invincibleTimer > 0` 则忽略
- **存档/检查点预留**：NotifyActivateRespawnPoint 传入 (position, checkpointId)；RespawnPointDetector 增加 checkpointId、order（order 用于场景首个排序，FindGameObjectsWithTag 后按 order 升序取最小）；DeathRespawnSystem 预留 Get/SetCurrentCheckpointId，本阶段可空实现

## 2. Config/资产检查清单

| 检查项                    | 要求                                                                                   |
| ------------------------- | -------------------------------------------------------------------------------------- |
| deathZoneLayer            | 需在 Project Settings → Tags and Layers 中新建 Layer「DeathZone」                      |

| respawnInvincibleDuration | 推荐 0.5 或 1（秒），已确认选 B                                                        |

## 3. 实现后验证项

1. 进入死亡区域后，玩家立即死亡并瞬移至复活点
2. 经过复活点后，再次死亡时在该复活点复活
3. 从未经过复活点时，在 defaultSpawnPosition 复活
4. 死亡→复活瞬移过程中，无穿模、无物理异常
5. 死亡期间无法移动、无法交互
6. 复活后 0.5–1 秒内进入死亡区域不触发死亡（无敌生效）
7. 接入 IDeathRespawnVFX 实现后，死亡/复活时能正确触发 OnDeath/OnRespawn；未接入时游戏正常运行
